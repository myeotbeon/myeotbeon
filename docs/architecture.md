# 구조

## 한눈에

```
 차량                      신호 출처                 엔진(순수 Kotlin)              바깥으로
┌──────────────┐   ┌──────────────────────┐   ┌──────────────────────┐   ┌────────────────────┐
│ Pleos Vehicle│   │ SignalSource         │   │ CompanionEngine      │   │ SpeechController   │
│ NaviHelper   │──▶│  ├ PleosSignalSource │──▶│  구간 · 멈춤 이유      │──▶│  Pleos TTS → 기본 TTS│
│ FusedLocation│   │  └ DemoSignalSource  │   │  신호 반응 · 우선순위   │   │  오디오 포커스       │
│ AAOS Car API │   │   (체험 모드)         │   │  대본 엔진(고정 문장)   │   ├────────────────────┤
└──────────────┘   └──────────────────────┘   └──────────────────────┘   │ Compose 화면        │
                          VehicleState               EngineAction         │ (주행 중 3줄 + 버튼2)│
                                                     EngineSnapshot       └────────────────────┘
                                   ▲                        ▲
                                   └──── TripController ────┘  (동행 한 번을 이끈다, 1초마다 onTick)
```

- `engine/` 은 안드로이드에 의존하지 않는 별도 Gradle 모듈입니다(Kotlin JVM). 안드로이드 클래스를 쓰면 컴파일되지 않습니다.
- 엔진은 시계를 갖지 않습니다. 모든 함수가 `nowMs` 를 받으므로, 같은 신호를 같은 순서로 넣으면 같은 말이 나옵니다(테스트로 확인).
- 신호 출처는 인터페이스 하나(`SignalSource`)이고 구현이 둘입니다. 체험 모드는 출처만 바꾼 것이라 엔진·음성·화면·저장은 같은 코드입니다.

## 엔진의 판단

### 구간(`StageCalculator`)

| 구간 | 조건 | 대본 상황 |
|---|---|---|
| 방금 출발 | 그 밖 | `depart` |
| 가는 중 | 10분의 1 이상 왔거나 출발 2분 경과 | `stage_onway` |
| 절반 | 10분의 4 이상 | `stage_half` |
| 거의 다 옴 | 4분의 3 이상이고 남은 시간 20분 이하 | `stage_near` |
| 곧 도착 | 남은 시간 5분 이하, 또는 근접 알림 | `stage_5min` |
| 도착 | 내비 도착 이벤트, 또는 목적지 근처(60초·150m·근접 알림) + P단 | `arrive` |

구간은 앞으로만 갑니다. 길을 다시 찾아 남은 시간이 늘어도 "절반" 뒤에 "가는 중"이라고 말하지 않습니다.
시간은 분 숫자가 아니라 구간 말로 전합니다.

### 먼저 말해 주기 간격(`IntervalPolicy`)

자동 = 남은 시간의 1/6 을 4~10분으로 제한(남은 시간을 모르면 5분). 5분, 10분, 끔.
어떤 말이든 한 뒤로 간격을 다시 셉니다. 서 있는 동안과 '잠시 조용히' 중에는 하지 않습니다.

### 멈춤 이유(`StopClassifier`)

더 구체적인 사실이 앞섭니다: 도착 → 운전자 복귀 → 운전자 이탈 → 경유지 정차 → 정체 → 신호 대기.

| 이유 | 조건 | 다시 말하기 |
|---|---|---|
| 신호 대기 | 주행 단에서 20초 이상 정지 | 쿨다운 60초, 계속 서 있으면 120초마다 |
| 정체 | 위와 같고 내비가 경로 정체를 알림 | 위와 같음 |
| 경유지 정차 | 출발한 뒤 P단 5초 이상 | 한 번 |
| 운전자 이탈 | P단 + 운전석 문이 열린 적 있음 + 운전석 비움 + 동승 좌석 점유 | 75초마다 짧게 |
| 운전자 복귀 | 이탈 뒤 운전석 점유 | 한 번 |
| 도착 | 위 표 | 한 번. 그 뒤로는 말하지 않음 |

'정지'는 속도 신호가 살아 있으면(한 번이라도 5km/h 이상) 속도 1km/h 미만으로, 아니면 브레이크 페달로 봅니다.
문 신호가 없는 차는 좌석 신호만으로 운전자 이탈을 보고, 좌석 신호가 없는 차는 이 기능이 꺼집니다.

### 신호 반응

| 신호 | 동승자에게 | 운전자에게 |
|---|---|---|
| 주행 중 문 열림 | 즉시(하던 말을 끊고) "문은 닫아 주세요" | 화면 + 알림음, 열려 있는 동안 15초마다 |
| 창문 30% 이상(설정 가능) | "손은 안에 두세요" 한 번(10%p 더 닫혔다 다시 열리면 또) | 화면 한 줄 |
| 안전띠 풀림 | 권유 2회(0초, 30초) | 60초 뒤에도 풀려 있으면 화면 + 알림음 |

P단에서는 문·창문·안전띠를 알리지 않습니다(내리는 중일 수 있으므로).

### 우선순위와 쿨다운

`안전 알림 > 멈춤 > 대답 > 먼저 말하기`

- 통로가 비어 있으면(마지막 말이 끝나고 1.5초 뒤) 바로 말합니다.
- 누가 말하는 중이면 우선순위가 높을 때만 끊고 말합니다. 안전 알림은 기다리지 않습니다.
- 그렇지 않으면 기다렸다가 말하되, 20초가 지나거나 그 사이 사실이 바뀌면(신호가 바뀌어 다시 출발) 버립니다.
- `잠시 조용히`(10분): 먼저 말하기·멈춤 안내·대답을 하지 않습니다. 문 열림, 도착, 그리고 **운전자가 차에 없는 동안의 안내**는 합니다.
  `다시 말씀드리기`를 누르면 풀립니다.

### 대본 엔진

- 상황마다 변형 3개를 순서대로 돌려 씁니다. 무작위가 없어 재현됩니다.
- 빈칸은 `{호칭}`, `{곳}`, `{운전자}` 셋. `{운전자:이}` 처럼 조사 표기를 붙이면 받침을 보고 고릅니다(이/가, 은/는, 을/를, 과/와, 으로/로, 이에요/예요).
- 화제 전환 한마디(`redirect_*`)는 대답 두 번에 한 번 붙입니다. 사용자가 직접 쓴 한마디는 그대로 읽습니다.
- 동승자 카드 둘째 줄은 대본의 두 가지 꼴을 모두 받습니다: 구간별 상황(`card_stage_depart`·`onway`·`half`·`near`·`arrive`,
  서 있을 때 `card_stop`, 운전자가 내려 있을 때 `card_driver_away`) 또는 한 상황 `card_stage` 에 구간 순서대로 6줄.
  변형이 여럿이어도 첫째 것만 써서, 한 번의 이동에서 카드의 말투가 바뀌지 않습니다.

### 대본 검사기(`ScriptValidator`)

| 규칙 | 내용 |
|---|---|
| R1 | 동승자에게 하는 줄은 `{호칭}` 으로 시작 |
| R2 | 한 문장 18음절 이하, 한 줄 두 문장 이하(화제 전환은 한 문장). 음절은 예시값(어머니·큰딸 집·따님)으로 채우고 부호·공백을 빼고 셈 |
| R3 | 금지어: 아까, 또, 다시 말, 말했, 말씀드렸, 기억, 몇 번, 왜 자꾸, 잊, 모르, 틀렸, 문장 처음의 아니에요 |
| R4 | 변형 둘 이상, 서로 다른 문장 |
| F | 슬롯 3개와 조사 표기 6개만, 운전자 줄은 호칭 없이, 카드 줄은 16자 이하 |
| S | 몸을 창밖으로 내밀게 할 수 있는 말(내밀, 밖으로) 금지 |
| D | 병명·환자라는 말 금지 |

앱에 들어가는 대본 파일 전체가 이 검사를 통과하는지를 단위 테스트가 확인합니다.
대본만 따로 검사하려면 `./gradlew :engine:validateScript -Pfile=<대본 파일>` (결과는 `engine/build/script-report.txt`),
새 대본으로 엔진 테스트 전체를 돌려 보려면 `./gradlew :engine:test -PscriptFile=<대본 파일>`.

## 화면과 주행 규제

| 화면 | 주행 중 | 내용 |
|---|---|---|
| 동행 중 | 열림 | 글 세 줄(누구·어느 자리 / 어디·어느 구간 / 마지막 안내) + 큰 버튼 둘 |
| 동승자 카드 | 열림 | 큰 글자 두 줄 |
| 출발 전 설정, 오늘의 기록, 환경설정 | **잠김** | 주행 규제(`CarUxRestrictions`) 중에는 잠금 안내만 보임 |

- 주행 중 화면에는 스크롤·움직이는 그림·긴 글·글자 입력이 없습니다. `동행 끝내기`도 정차 중에만 보입니다.
- 넓은 창(가로)과 좁은 창(세로) 모두에 맞춥니다: 900dp 이상이면 왼쪽 메뉴, 아니면 아래 메뉴.
- 색은 밤·낮 두 벌이고, 글자 대비 4.5:1 이상을 단위 테스트로 검사합니다. 가장 작은 글자가 22sp 입니다.
- 버튼은 누르면 95% 로 줄고 바탕색이 바뀝니다.

## 동행 한 번의 흐름(`TripController`)

1. `start(config)` — 설정을 '자주 가는 길'로 저장, 엔진을 만들고 소개말, 포그라운드 서비스 시작.
2. 신호가 바뀔 때마다 `engine.onSignals`, 1초마다 `engine.onTick`. 엔진이 돌려준 `EngineAction` 을 음성·알림음으로 옮기고 `EngineSnapshot` 을 화면에 냅니다.
3. `end()` — 엔진에서 횟수 기록을 받아 저장, 서비스 종료. 도착한 뒤 10분이 지나도 끝내지 않으면 스스로 끝냅니다.

포그라운드 서비스는 동행 중에만 떠 있습니다. 부팅 때 스스로 시작하지 않고, 차량 신호는 폴링이 아니라 리스너로 받습니다
(예외: 내비의 남은 시간은 콜백으로만 와서, 동행 중에만 30초마다 다시 묻습니다).
