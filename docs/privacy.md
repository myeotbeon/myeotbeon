# 개인정보와 존엄

## 원칙

1. 앱은 기기 밖으로 내보내지 않는다(서버 없음, 앱 코드에 네트워크 호출 없음. SDK 가 넣는 인터넷 권한은 아래 '네트워크').
2. 목소리를 남기지 않는다.
3. 남기는 것은 아래 표의 네 가지(자주 가는 길, 이동 기록, 환경설정, 켰을 때의 도착 지점)뿐이고, 언제든 지울 수 있다.
   누가 무슨 말을 했는지는 남기지 않는다.
4. 앱 이름과 화면에 병명이나 환자라는 말을 쓰지 않는다.

- 기록에는 누가 무슨 말을 했는지, 몇 시에 무엇을 물었는지가 없습니다. 한 번의 이동에 시작 시각·걸린 시간과 숫자 여섯 개뿐입니다.
- 저장 항목은 단위 시험(`PrivacyWordingTest`)이 앱이 실제로 쓰는 항목과 견줍니다. 새 항목을 저장하게 되면 시험이 깨지므로 이 표와
  README, 앱 안 개인정보 안내를 함께 고칩니다.
- `환경설정 > 모두 지우기`는 자주 가는 길(도착 지점 포함), 기록, 환경설정을 한 번에 지웁니다.
- 클라우드 백업과 기기 간 이동에서 앱 데이터를 제외했습니다(`allowBackup="false"`, `data_extraction_rules.xml`).
- 개발자 패널의 '연결 기록'은 메모리에만 있고(최근 40줄), 개인정보를 넣지 않습니다.

## 네트워크

- 앱 코드에는 네트워크 호출이 없고, 서버도 없습니다. 생성형 AI 를 부르지 않습니다(말은 미리 써 둔 고정 대본).
- 앱 매니페스트는 `android.permission.INTERNET` 을 선언하지 않습니다(단위 테스트로 확인).
- 다만 Pleos TextToSpeech·SpeechToText SDK 와 그 안의 universal-access 라이브러리가 **병합 매니페스트에 INTERNET 을 넣습니다.**
  앱은 두 SDK 를 `Mode.ON_DEVICE`(기기 안 엔진, 앱 등록 불필요)로만 씁니다. SDK 내부 동작은 앱이 통제할 수 없으므로,
  "앱이 인터넷 권한을 갖지 않는다"고는 말하지 않습니다.
- Pleos TextToSpeech 를 쓸 수 없으면 기기의 안드로이드 기본 TTS 엔진으로 읽습니다. 그 엔진이 기기 안에서만 합성하는지는 앱이 정하지
  못합니다(앱 안 개인정보 안내에도 그렇게 적었습니다). 2026-11-11 Pleos Connect 에뮬레이터에서는 Pleos 기기 안 엔진이 말했습니다.

## 권한

| 권한 | 쓰는 곳 | 언제 묻나 |
|---|---|---|
| `pleos.car.permission.CAR_SEATS` / `CAR_DOORS` / `CAR_WINDOWS` / `CAR_DRIVE` | 좌석 점유·안전띠 / 문 / 창문 / 브레이크 | 설치 때(normal) |
| `pleos.car.permission.NAVI_ROUTE` | 목적지 이름·남은 시간·도착 | 설치 때 |
| `pleos.car.permission.TTS_SERVICE` | 말하기 | 설치 때(에뮬레이터에서 묻지 않고 허용됨). 사용자 허용이 필요한 종류로 정의된 차에서만 앱을 열 때 묻도록 해 두었다 |
| `pleos.car.permission.STT_SERVICE` | 물으면 대답하기(실험 기능) | 위와 같음. 기능을 켜지 않으면 마이크를 쓰지 않음 |
| `pleos.car.permission.FUSED_LOCATION` | 도착 지점 기억과 근접 알림 | **사용자 허용**(dangerous). '도착 지점 기억하기'를 켤 때만 |
| `android.car.permission.CAR_POWERTRAIN` | 변속단 | 설치 때 |
| `android.car.permission.CAR_SPEED` | 속도(정지 판단 보조) | **사용자 허용**(dangerous). 첫 실행 안내(정차 중)에서 한 번 권하고, 환경설정의 `속도 신호 허용하기`로도. 허용 창은 '위치 정보에 액세스'로 뜬다(에뮬레이터, 위치 권한 묶음). 허용하지 않아도 앱은 돈다 |
| `android.permission.POST_NOTIFICATIONS` | 앱이 화면 뒤에 있을 때 급한 운전자 알림을 한 줄 알림으로 | **사용자 허용**(안드로이드 13 이상). 첫 실행 안내(정차 중)에서 한 번 권하고, 환경설정의 `알림 허용하기`로도. 동행을 시작할 때는 묻지 않는다(시스템 창이 동행 화면을 덮지 않게). 허용하지 않아도 앱은 돈다 |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | 동행 중 안내 유지 | 설치 때 |

- 사용자 허용이 필요한 권한이 셋(위치, 속도, 알림) 있으므로, 기획서·영상에서 '일반 권한만 쓴다'고 쓰면 사실과 다릅니다.
- 차량 제어(`CONTROL_CAR_*`)와 경고등(`PRIVATE_CAR_SAFETY`) 권한은 선언하지 않습니다.

## 음성 인식(실험 기능)에 대해

- 기본은 꺼져 있습니다. 환경설정에서 켜야 하고, 동행 중에만, 차가 말하지 않을 때만 듣습니다.
- 기기 안 엔진(`Mode.ON_DEVICE`)만 씁니다.
- 인식 결과는 `IntentMatcher` 가 "어디 가 / 언제 도착 / 다 왔어 / 왜 안 가 / 집에 가자" 중 무엇인지만 가려내고 문장은 버립니다.
  가려낸 종류도 저장하지 않고, 대답한 횟수만 셉니다.
- 누가 한 말인지는 가리지 못합니다. 운전자의 통화나 라디오의 같은 말에도 대답할 수 있어, 같은 물음에는 18초 안에 다시 대답하지 않습니다
  (환경설정의 설명에도 적었습니다).

## 존엄

- 앱 이름, 화면, 대본에 병명·환자라는 말이 없습니다. 화면 글(`strings.xml`), 화면 코드, 대본, Gleo 스키마를 훑는 단위 테스트가 있습니다.
- 대본은 고치거나 따지거나 시험하지 않습니다. "아까", "또", "말씀드렸", "기억", "몇 번", "왜 자꾸" 같은 말은 검사기가 막습니다.
  운전자가 직접 쓴 화제 전환 한마디도 같은 검사를 통과해야 읽고, 통과하지 못하면 출발 전 설정에서 그 까닭을 바로 보입니다.
- 경고음으로 동승자를 놀라게 하지 않습니다. 급한 운전자 알림(주행 중 문 열림 등)에 내는 알림음은 짧고 낮은 소리입니다.
  차의 스피커(`STREAM_NOTIFICATION`)로 나므로 동승자에게도 들립니다(운전석 쪽으로만 보내지 못합니다).
- 창문 안내는 "손은 안에 두세요"처럼 할 일을 말합니다. 몸을 밖으로 내밀게 할 수 있는 표현은 검사기가 막습니다.
- 내비 목적지 이름이 '가는 곳'의 기본값으로 들어올 수 있습니다. 어르신께 들려줄 이름이므로 부르기 쉬운 이름으로 고쳐 쓰기를 권합니다
  (진료과 이름이 그대로 읽히지 않게).

## 주장의 범위

이 앱이 말하는 효과는 "차가 대신 말한 횟수"(먼저 말하기 + 다시 말씀드리기 + 물음 대답 + 멈춤 안내, 끝까지 소리 낸 것만)까지입니다.
운전자가 대답을 덜 했는지, 불안이 줄었는지는 재지 않습니다. 치료 효과를 주장하지 않으며, 안전장치도 아닙니다.
