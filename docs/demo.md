# 시연 순서

두 가지 방법이 있습니다. A 는 Pleos Connect 에뮬레이터의 가상 콘솔로 실제 차량 신호를 바꾸는 방법이고,
B 는 에뮬레이터 없이(또는 가상 콘솔 없이) 앱 안의 체험 모드로 같은 순서를 돌리는 방법입니다.

## A. 가상 콘솔(Virtual Console)로 — 약 3분

준비

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
adb forward tcp:8088 tcp:8088          # 브라우저에서 http://127.0.0.1:8088/
adb shell am start -n app.myeotbeonideun/.ui.MainActivity
```

- 에뮬레이터는 Cold boot 로 띄웁니다(빠른 부팅이면 차량 신호가 오지 않습니다).
- 앱의 `환경설정 > 차량 신호`에서 좌석 점유·문·창문·브레이크·변속단이 '사용'으로 보이는지 먼저 확인합니다.
  `개발자 패널`은 차량 모드에서 지금 읽히는 값과 연결 기록을 보여 줍니다.
- 처음 실행하면 안내가 한 번 나옵니다. `확인했어요`를 누릅니다.

| # | 가상 콘솔에서 | 앱이 하는 일 |
|---|---|---|
| 1 | Motion > Gear **P**. Convenience > Seat Occupancy 에서 **뒷좌석 오른쪽 = Occupied**, 운전석 = Occupied | 출발 전 설정의 '앉으신 자리'가 뒷좌석 오른쪽으로 자동 선택됨. 호칭 '어머니', 가는 곳 '큰딸 집'을 확인하고 `동행 시작` → "어머니, 저는 길을 알려 주는 목소리예요. 따님이 운전할 때 제가 알려 드릴게요." |
| 2 | Gear **D** | "어머니, 이제 출발해요. 큰딸 집으로 가요." 설정·기록 화면이 잠기고 동행 화면만 남음 |
| 3 | (앱에서) `다시 말씀드리기` 두 번 | 같은 사실을 다른 표현으로 두 번("…큰딸 집에 가요. 따님이 운전하고 있어요." / "…큰딸 집에 가는 길이에요. 따님이 운전해서 가요."). '가서 할 일'을 정했다면 대답 두 번에 한 번 화제 전환 한마디가 붙음("가서 같이 식사하세요.") |
| 4 | Brake Pedal **100%** 로 20초 유지 | "어머니, 잠깐 신호를 기다려요. 아직 가는 중이에요." → 브레이크를 0% 로 |
| 5 | Window Position 뒷좌석 오른쪽 **40%** | 동승자: "어머니, 창문이 열렸어요. 손은 안에 두세요." 운전자 화면: "같이 탄 분 쪽 창문이 열렸어요." → 0% 로 |
| 6 | Gear **P**, Door Position 운전석 **열림**, Seat Occupancy 운전석 **Empty** | "어머니, 따님이 잠깐 내렸어요. 금방 돌아와요." (75초마다 짧게 다시) |
| 6' | 운전석 **Occupied**, 문 **닫힘** | "어머니, 따님이 돌아왔어요. 다시 출발해요." |
| 7 | Gear **D**, Door Position 뒷좌석 오른쪽 **열림** | 운전자: 붉은 알림 한 줄("같이 탄 분 쪽 문이 열렸어요.") + 알림음. 동승자: "어머니, 문은 닫아 주세요. 아직 가는 중이에요." → 문 닫힘 |
| 8 | 내비 모의 주행으로 남은 시간 5분 이하 → 목적지에서 Gear **P** | 남은 시간이 3~5분이면 "어머니, 5분쯤 남았어요. 곧 큰딸 집이에요.", 3분 이하이면 "어머니, 거의 다 왔어요. 큰딸 집이 가까워요." → "어머니, 큰딸 집에 다 왔어요. 따님이 올 때까지 앉아 계세요." |
| 9 | (앱에서) `동행 끝내기` | 오늘의 기록: 직접 대답하지 않아도 된 횟수, 최근 8번 이동 |

참고

- 8번의 내비 값은 가상 콘솔로 바꿀 수 없습니다. 에뮬레이터 내비의 모의 주행이 이벤트를 주지 않으면,
  8번만 B 방법(체험 모드)으로 보이거나 도착을 P단 + '동행 끝내기'로 대신합니다.
- 주행 규제만 따로 켜려면: `adb shell cmd hmg_car_service --service drivingstate driving_regulation on` (끄기는 `off`).
- 좌석별 안전띠는 가상 콘솔에 없어 B 방법으로만 보일 수 있습니다(모의 입력임을 밝힙니다).
- 화면 녹화: `adb exec-out screenrecord --output-format=h264 - > screen.h264`
- 이 순서는 문서와 엔진 테스트로 맞춘 것이고, 에뮬레이터에서 실제로 해 본 기록은 아직 없습니다.

## B. 체험 모드로 — 약 2분 30초

Pleos 서비스가 없는 기기에서는 자동으로 체험 모드가 됩니다. 에뮬레이터에서는 `환경설정 > 체험 모드`를 켭니다.
화면에 `체험 모드` 표시가 붙습니다.

1. `출발` 화면에서 `동행 시작`. (체험 모드의 모의 내비 목적지 '큰딸 집'과 좌석 신호로 빈칸이 채워져 있습니다.)
2. `설정 > 개발자 패널`. 넓은 창에서는 왼쪽에 동행 화면, 오른쪽에 조작판이 함께 보입니다.
3. `시연 재생`을 누르면 아래 순서가 자동으로 지나갑니다. 지금 단계가 조작판 위에 표시됩니다.

| 시각(초) | 모의 신호 | 앱이 하는 일 |
|---|---|---|
| 0 | 기어 D | 출발 안내 |
| 14 | (`다시 말씀드리기`를 두 번 눌러 보세요) | 같은 사실, 다른 표현 |
| 32 | 브레이크 밟음 | 20초 뒤 신호 대기 안내 |
| 62 | 남은 시간 절반 | "절반쯤 왔어요" |
| 72 | 동승 좌석 창문 40% | 창문 안내 |
| 83 | 기어 P, 운전석 문 열림, 운전석 비움 | 운전자 이탈 안내 |
| 97 | 운전석 점유, 문 닫힘 | 운전자 복귀 안내 |
| 106 | 기어 D | |
| 112 | 동승 좌석 문 열림 | 운전자 알림 + 동승자 안내 |
| 124 | 남은 시간 2분 | "거의 다 왔어요" |
| 134 | 기어 P | 도착 안내 |

4. `동행 끝내기` → 오늘의 기록.

손으로 바꿔 보려면 `시연 재생` 대신 조작판의 칩을 누릅니다. 동행 중에 기어를 D 에 두면 모의 주행으로
남은 시간이 스스로 줄어듭니다(실제의 4배 빠르기, 12분 길이 3분).
