# 시연 순서

두 가지 방법이 있습니다. A 는 Pleos Connect 에뮬레이터의 가상 콘솔로 실제 차량 신호를 바꾸는 방법이고,
B 는 앱 안의 체험 모드(모의 신호)로 같은 순서를 돌리는 방법입니다. 내비 구간 변화와 안전띠는 B 로만 보일 수 있습니다.

A 순서는 2026-11-11 Pleos Connect Emulator v2.1.0 에서 커밋 40f6371 빌드로 한 번 돌렸습니다(README '테스트 환경').
그때와 달라진 것 — 좌석 값을 사실대로 넣고 앱이 극성을 맞추는 것, 내비 없는 길의 정차 문장, '도착했어요', 기록의 '차가 대신 말했어요' —
은 그 뒤 빌드에 들어간 것이라 아래 표의 해당 줄은 에뮬레이터에서 다시 확인하기 전입니다.

## A. 가상 콘솔(Virtual Console)로 — 약 4분

준비

```bash
adb install -r "apk/개인참가_몇번이든_release.apk"     # 또는 app/build/outputs/apk/release/app-release.apk
adb forward tcp:8088 tcp:8088                           # 가상 콘솔: 브라우저에서 http://127.0.0.1:8088/
adb shell am start -n app.myeotbeonideun/.ui.MainActivity
```

- 에뮬레이터는 Cold boot 로 띄웁니다(빠른 부팅이면 차량 신호가 오지 않습니다).
- 처음 실행하면 안내가 한 번 나옵니다. 속도 권한이 없으면 여기서 '속도 신호 허용하기'를 권합니다. 허용 창은 "위치 정보에 액세스"로 뜹니다
  (속도 권한이 위치 권한 묶음으로 표시됨). 허용하면 정지를 속도로 알고, 허용하지 않으면 '주행 단에서 브레이크를 20초 넘게 밟고 있음'으로 봅니다.
  `확인했어요`를 누릅니다.
- `환경설정 > 차량 신호`에서 좌석 점유·문·창문·안전띠·브레이크·변속단·주행 규제·내비·위치(속도는 허용 뒤)가 '사용'인지 봅니다.
  `개발자 패널`(차량 모드)은 지금 읽히는 값, 좌석 값 해석("좌석 값: 반대로(운전석 기준 자동)")과 SDK 원시 값, 연결 기록을 보여 줍니다.

### 가상 콘솔을 바꾸는 두 방법

1. **브라우저 페이지**: `http://127.0.0.1:8088/` 에서 기어·페달·문·창문·좌석 점유를 누릅니다.
2. **시연 도우미(HTTP, adb 없음)**: [`tools/demo_console.py`](../tools/demo_console.py). `python tools/demo_console.py` 로 실행해
   아래 표의 순서를 단계마다 Enter 로 보냅니다(`s` 건너뛰기, `q` 끝내기,
   `--from N` N단계부터, `--list` 목록, `--dry-run` 보내지 않고 보기). 앱의 버튼(동행 시작, 다시 말씀드리기, 도착했어요)은 사람이 누릅니다.
   단계마다 콘솔의 지금 값(`GET /vehicle/state`)을 한 줄로 보입니다. `python tools/demo_console.py --selftest` 는 이 PC 안의 가짜 콘솔로
   도우미 자체를 시험합니다(에뮬레이터가 필요 없음). Python 3.8 이상, 표준 라이브러리만 씁니다.

가상 콘솔 HTTP API(2026-11-11 확인). 쓰기는 **브라우저 세션이 살아 있을 때만** 됩니다: 3초 안에 한 번씩 `POST /browser/session?client=<아무 이름>` 을
보내지 않으면 쓰기가 `{"error":"emulator_inactive"}` 로 거절됩니다(도우미는 1초마다 보내고, 끝날 때 `&closing=1`).

| 할 일 | 요청 |
|---|---|
| 세션 살리기 | `POST /browser/session?client=demo` (3초 안에 한 번씩) |
| 기어 | `PUT /vehicle/gear?gear=Park` / `Reverse` / `Neutral` / `Drive` |
| 속도·페달 | `PUT /vehicle/controls?speed=40&accelerator=20&brake=0` (speed 0~240, accelerator·brake 0~100) |
| 문 | `PUT /vehicle/body?door_rr=true` (`door_fl`·`door_fr`·`door_rl`·`door_rr`, true = 열림) |
| 창문 | `PUT /vehicle/body?window_rr=40` (`window_fl`…`window_rr`, 0~100%) |
| 좌석 점유 | `PUT /vehicle/seat?kind=occupied&area=driver&value=true` (`driver`·`passenger`·`rear_left`·`rear_right`) |
| 지금 값 | `GET /vehicle/state`, 바꿀 수 있는 값 목록 `GET /vehicle/catalog` |

curl 로 할 때는 세션을 다른 창에서 살려 둡니다.

```bash
while true; do curl -s -X POST "http://127.0.0.1:8088/browser/session?client=demo" >/dev/null; sleep 1; done   # 창 1
curl -s -X PUT "http://127.0.0.1:8088/vehicle/gear?gear=Drive"                                                 # 창 2
```

### 순서

| # | 가상 콘솔에서 | 앱이 하는 일 |
|---|---|---|
| 1 | Gear **P**. 문 모두 닫힘, 창문 0%. Seat Occupancy 를 **사실대로**: 운전석 = Occupied, 뒷좌석 오른쪽 = Occupied, 나머지 Empty | 출발 전 설정의 '앉으신 자리'가 '뒷좌석 오른쪽 (앉아 계심)'으로 자동 선택됨(에뮬레이터는 좌석 값이 반대로 오지만, 앱이 운전석 기준으로 '반대로'를 정함) |
| 2 | (앱에서) 호칭 '어머니', 가는 곳 '큰딸 집', 운전하는 사람 '따님' → `동행 시작` | "어머니, 저는 길을 알려 주는 목소리예요. 따님이 운전할 때 제가 알려 드릴게요." |
| 3 | Gear **D**, 속도 40 | "어머니, 이제 출발해요. 큰딸 집으로 가요." 메뉴의 출발·기록·설정이 잠기고, `도착했어요`·`동행 끝내기`가 사라짐 |
| 4 | (앱에서) `다시 말씀드리기` 두 번 | 같은 사실을 다른 표현으로 두 번("…큰딸 집에 가요. 따님이 운전하고 있어요." / "…큰딸 집에 가는 길이에요. 따님이 운전해서 가요."). '가서 할 일'을 정했다면 대답 두 번에 한 번 화제 전환 한마디가 붙음("가서 같이 식사하세요.") |
| 5 | 속도 **0**, Brake **100%** 로 20초 → 다시 속도 30, 브레이크 0 | "어머니, 잠깐 신호를 기다려요. 아직 가는 중이에요." |
| 6 | Window 뒷좌석 오른쪽 **40%** → 0% | 동승자: "어머니, 창문이 열렸어요. 손은 안에 두세요." 운전자 화면: "같이 탄 분 쪽 창문이 열렸어요." |
| 7 | Door 뒷좌석 오른쪽 **열림** → 닫힘 | 운전자: 붉은 한 줄("같이 탄 분 쪽 문이 열렸어요.") + 알림음. 동승자: "어머니, 문은 닫아 주세요. 아직 가는 중이에요." 차 자체의 '도어 열림' 경고도 계기판에 뜸. 닫으면 붉은 줄이 사라짐 |
| 8 | 속도 0, 브레이크, Gear **P** (내비 안내 없이 간 길) | 5초쯤 뒤 "어머니, 차를 세웠어요. 따님이 알려 드릴 때까지 앉아 계세요." — 도착인지 모르므로 도착을 부정하지 않음. 아래 줄에 `도착했어요`·`동행 끝내기` |
| 9 | Door 운전석 **열림**, Seat 운전석 **Empty**, 문 닫힘 | 2.5초쯤 뒤 "어머니, 따님이 잠깐 내렸어요. 금방 돌아와요." (75초마다 짧게 다시) |
| 9' | (선택) 운전자가 없는 동안 Door 뒷좌석 오른쪽 **열림** → 닫힘 | 바로 "어머니, 앉아서 따님을 기다려요." 문을 막지는 못함(안전장치가 아님) |
| 10 | Door 운전석 열림, Seat 운전석 **Occupied**, 문 닫힘 | "어머니, 따님이 돌아왔어요. 다시 출발해요." 9' 를 했으면 붉은 한 줄 "차에서 내린 사이 같이 탄 분 쪽 문이 열렸어요."와 알림음(1분) |
| 11 | (앱에서) `도착했어요` | "어머니, 큰딸 집에 다 왔어요. 따님이 올 때까지 앉아 계세요." 말이 끝나면 동행이 끝나고 오늘의 기록으로 넘어감 |
| 12 | (앱에서) 오늘의 기록 → 출발 | "N번 차가 대신 말했어요"와 그 세부(먼저 말함·다시 말씀드리기·물음에 대답·멈춤 안내), 문·창문·안전띠 안내는 따로 셈. 출발 화면의 '자주 가는 길'에 "큰딸 집 · 어머니 · 눌러서 시작" |

시연 도우미의 단계 번호는 이 표와 다릅니다(콘솔 조작을 더 잘게 나눴습니다). `--list` 로 봅니다.

### 내비로 실제 목적지 넣기(선택)

1. 에뮬레이터 홈의 내장 지도(내비)에서 목적지를 검색해 고르고 안내를 시작합니다(2026-11-11: '병원' 검색 → 9분·1.9km 경로).
2. 앱으로 돌아오면 출발 전 설정의 '가는 곳'이 비어 있을 때 내비 목적지 이름이 들어옵니다. 어르신께 들려줄 이름이므로 부르기 쉬운 이름으로
   고칩니다(진료과 이름이 그대로 읽히지 않게).
3. 개발자 패널에 "목적지 … · 남은 540초 / 전체 540초"처럼 보입니다(남은 시간의 단위는 초).

이 에뮬레이터에서는 내비 위치가 움직이지 않습니다(내보내는 NMEA 체크섬이 틀려 내장 내비가 버림). 그래서 남은 시간은 재계산으로만 조금 줄고,
구간("절반쯤", "거의 다 왔어요")이 바뀌거나 내비 도착 안내가 나지 않습니다. 또 내비가 남은 시간이 넉넉하다고(5분 넘게, 1km 넘게) 알리는
동안 P단에 서면 '경유지 정차'("어머니, 잠깐 쉬었다 가요. 아직 다 온 건 아니에요.")가 맞는 말이 됩니다. 8번의 내비 없는 길의 정차와
`도착했어요`를 보이려면 그 전에 내비 안내를 끕니다. 구간 변화는 B 로 보입니다.

### 참고

- 주행 규제만 따로 켜려면: `adb shell cmd hmg_car_service --service drivingstate driving_regulation on` (끄기는 `off`).
- 좌석별 안전띠는 가상 콘솔에 없어 B 방법으로만 보일 수 있습니다(모의 입력임을 밝힙니다).
- Gleo 를 흉내 내려면(Gleo 음성 → 함수 경로는 확인하지 못했습니다. 아래는 Gleo 가 보낼 것과 같은 꼴의 방송으로, '다시 말하기'는
  2026-11-11 에 확인했고 `arrived` 는 그 뒤 빌드라 확인 전입니다):

  ```bash
  # 다시 말씀드리기(동행 중)
  adb shell "am broadcast -a REPEAT_TRIP_ANSWER -n app.myeotbeonideun/.gleo.GleoActionReceiver --es ACTION_PARAM '{}'"
  # 다 왔다고 말하기(P단에서만 받음)
  adb shell "am broadcast -a REPEAT_TRIP_ANSWER -n app.myeotbeonideun/.gleo.GleoActionReceiver --es ACTION_PARAM '{\"arrived\":true}'"
  ```

- 화면 녹화: `adb exec-out screenrecord --output-format=h264 - > screen.h264`. 앱의 음성은 에뮬레이터 gRPC 의 오디오 스트림으로 받아
  영상에 넣을 수 있습니다(2026-11-11 확인).

## B. 체험 모드로 — 약 2분 30초

차량용이 아닌 기기(adb 로 설치한 휴대폰·태블릿 등)에서는 체험 모드로만 돕니다. Pleos Connect 에뮬레이터와 차에서는 `환경설정 > 체험 모드`를
켭니다(차량 신호를 받지 못해도 스스로 체험 모드로 넘어가지 않습니다). 화면에 `체험 모드` 표시가 붙습니다.
체험 모드여도 실제 차(가상 콘솔)가 주행 중이면 출발 전 설정·기록·환경설정·개발자 패널이 잠깁니다. 가상 콘솔의 기어를 P 에 둡니다.

1. `출발` 화면에서 `동행 시작`. (체험 모드의 모의 내비 목적지 '큰딸 집'과 좌석 신호로 빈칸이 채워져 있습니다.)
2. `설정 > 개발자 패널`. 넓은 창에서는 왼쪽에 동행 화면, 오른쪽에 조작판이 함께 보입니다.
3. `시연 재생`을 누르면 아래 순서가 자동으로 지나갑니다. 지금 단계가 조작판 위에 표시됩니다.

| 시각(초) | 모의 신호 | 앱이 하는 일 |
|---|---|---|
| 0 | 기어 D | 출발 안내 |
| 14 | (`다시 말씀드리기`를 두 번 눌러 보세요) | 같은 사실, 다른 표현 |
| 32 | 브레이크 밟음 | 20초 뒤 신호 대기 안내 |
| 62 | 남은 시간 절반 | "절반쯤 왔어요" |
| 72 | 동승 좌석 창문 40% | 창문 안내 |
| 83 | 기어 P, 운전석 문 열림, 운전석 비움 | 운전자 이탈 안내 |
| 97 | 운전석 점유, 문 닫힘 | 운전자 복귀 안내 |
| 106 | 기어 D | |
| 112 | 동승 좌석 문 열림 | 운전자 알림 + 동승자 안내 |
| 124 | 남은 시간 2분 | "거의 다 왔어요" |
| 134 | 목적지 앞(남은 20초·50m)에서 기어 P | 도착 안내 |

4. `동행 끝내기` → 오늘의 기록.

손으로 바꿔 보려면 `시연 재생` 대신 조작판의 칩을 누릅니다(안전띠 풂, 정체, '도착 알림 보내기' 포함). 동행 중에 기어를 D 에 두면 모의 주행으로
남은 시간이 스스로 줄어듭니다(실제의 4배 빠르기, 12분 길이 3분).
